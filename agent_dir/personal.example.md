# Personal Information for Job Applications

Copy this to `agent_dir/personal.md` and replace every value with your own. The agent reads
that file once per job and treats it as the only source of truth for form fields — it is
told never to invent a value that is not here, so anything you leave out is left blank.

Structure is free-form; headings and bullets just have to be readable. Add whatever your
target applications keep asking for.
